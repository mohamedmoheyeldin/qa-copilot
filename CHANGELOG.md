# Changelog

## 1.0.0

- **Dashboard** with activity, test case mix, severity, frameworks, and estimated time saved. Sample data for presentations.
- **Frameworks**: Playwright (TypeScript, JavaScript, Python, Java, C#), Cypress (TypeScript, JavaScript), Selenium (Java, Python, C#, TypeScript, JavaScript), and WebdriverIO (TypeScript, JavaScript).
- **Cucumber BDD** for every framework: feature file, step definitions, and hooks for Cucumber.js, Cucumber JVM, pytest-bdd, behave, Reqnroll, the Cypress preprocessor, and WebdriverIO Cucumber.
- **Code that follows your options**: demo results update instantly; AI results can be updated with AI (keeping the cases) or converted offline.
- **Exports**: PDF, Word, Excel, and Markdown for bug reports and test cases, plus a zip of all code files.
- **AI providers**: Anthropic, OpenAI, Google Gemini, and any OpenAI-compatible endpoint, with per-provider keys and Load models.
- **History** backup and restore, automatic upgrades of older entries.
- Unit tests (Vitest) for the code generator, providers, exports, history, and stats.

## 0.2.0

- History, editable test cases, clearer AI errors, Test connection, accessibility checks, theme switcher.

## 0.1.0

- Bug report writer and test case generator with demo, your API key, and prompt-only modes.
